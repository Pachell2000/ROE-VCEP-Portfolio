# ROE Cybersecurity Training Portfolio

This portfolio documents hands-on labs and capstone projects completed during ROE Cybersecurity training.

## Portfolio Purpose

Each project will explain:
- What I built and why.
- The tools and configurations I used.
- How I tested the results.
- Problems I encountered and how I resolved them.
- What I learned and personally contributed.

## Skills Practiced

- Network design using Cisco Packet Tracer.
- IP addressing and subnetting.
- Router and switch configuration.
- Connectivity testing and troubleshooting.
- Technical documentation.
